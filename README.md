**零外部贴图 · 零外部 3D 模型 · 零外部音频文件 · 浏览器即开即玩的两款截然不同的 3D 网页游戏**

致敬近期 GitHub 爆火的 **Claude Fable 5.2「纯代码浏览器 3A 视觉范式」**（[`awesome-fable-5.2`](https://github.com/fengyiqicoder/awesome-fable-5.2)），本仓库收录了两款美术风格、镜头视角与声学引擎截然相反的单文件 3D 游戏，并提供统一的 **双作切换门户 [`index.html`](./index.html)**：

1. **作品一：《星月夜骑士 · STARRY NIGHTRIDER》**（[`starry-nightrider.html`](./starry-nightrider.html)，约 87 KB 单文件原生 WebGL2）
   - 致敬榜一作品 *Starry Nightrider* 与 *Oil Paint*。实时各向异性 Kuwahara 厚涂油画笔触滤镜、随风起伏且随马蹄分开的 1,450 株金色麦浪、1889 圣雷米漩涡星穹，以及纯代码古典木吉他/揉弦大提琴/竖琴原声合成。

   - 致敬 *Saltline* 第一人称战术射击。半浮点 HDR 风暴钠灯环境反射、湿地积水涟漪 PBR 材质、44m 岸桥起重机与 205m 货轮、MK-18 全息红点步枪，以及室内外机库卷积混响实时物理枪声。

## 作品一：《星月夜骑士 · STARRY NIGHTRIDER》

### 核心亮点
- **实时厚涂油画着色器管线（WebGL2 `#version 300 es` 四通道渲染）**
  - **流动的《星月夜》天穹**：双旋涡卷曲流场（Curl-Flow Nebula）实时演化出梵高标志性的中央 S 型星云巨浪、藏红花色新月光环、9 颗脉动星辰与 **5 座可由玩家亲自点亮的夜空星座连线**。
  - **各向异性 Kuwahara 油画后处理滤镜**：沿画面明暗结构切线方向聚合油彩笔触，叠加颜料边缘高光（Impasto Bevel Catchlight）与亚麻画布纹理，支持按 `B` 键在 **「清透原画 / 厚涂名画 / 狂野梵高」** 三档之间实时切换对比。
  - **GPU 实例化金色麦浪与立体漂浮笔触**：1,450 株普罗旺斯麦穗随夜风起伏，并在骏马驰骋经过时自动向两侧分开；550 道立体油彩笔触悬浮于山谷夜空。
- **第三人称奔马逆运动学与写生冒险玩法**
  - 化身草帽画家文森特，骑乘四足双关节奔马穿越圣雷米石拱桥、尖顶教堂村落、旋转风车山脊与火焰柏树林。
  - 收集金色星芒积攒画笔能量，按 `Shift` 或 `左键` 发动 **「星流画笔冲刺」** 将游荡的 **夜魇墨涡** 绘成漫天金星；点亮全部 5 座星象画架后，登顶北方 **「新月山巅」** 跃入巨型金色画框完成传世画作。
- **100% 纯代码古典原声合成器（「夜曲原声琴房」）**
  - 实时物理合成古典木吉他分解和弦、带揉弦泛音的独奏大提琴、星宫竖琴刮奏（Harp Glissando）、D-Lydian 调式钢片琴星芒音，以及草地/麦浪/石桥/浅滩踏水四种四拍子真实马蹄拟音。

### 操作指南（星月夜骑士）
| 动作 | 键鼠操作 | 触屏操作 |
| :--- | :--- | :--- |
| **策马加速 / 减速转向** | `W` `A` `S` `D` 或 `方向键` | 左侧虚拟摇杆 |
| **星流画笔冲刺（净除夜魇墨涡）** | `Shift` 或 `鼠标左键` | `冲刺` 按钮 |
| **骏马腾跃（穿越高空星环加速）** | `Space` 或 `鼠标右键` | `腾跃` 按钮 |
| **实时切换油画笔触强度** | `B`（清透原画 / 厚涂名画 / 狂野梵高） | 顶栏 `笔触` 按钮 |
| **切换摄影机机位** | `C`（经典追尾 / 仰望星穹 / 全景画卷） | 顶栏 `视角` 按钮 |
| **环顾星穹 / 暂歇菜单** | 移动或拖拽鼠标 / `P` 或 `ESC` | 顶栏 `暂歇` 按钮 |

## 作品二：《断潮行动 · SALTLINE: BLACK TIDE》

### 核心亮点
- **雨夜港区照片级氛围渲染（HDR PMREM + UnrealBloom）**：半浮点程序化风暴夜空环境反射、湿混凝土积水倒影、室内外雨水遮蔽与机库卷积混响枪声切换。
- **硬表面程序化建模与首领战**：MK-18 断潮全息红点步枪（三段换弹与抛壳物理）、「猎鸥」激光无人机、「猎犬」四足机甲，以及需要 `Q` 键 **EMP 电磁脉冲手雷**破盾的「港务官」重装机甲。

### 操作指南（断潮行动）
| 动作 | 键鼠操作 | 触屏操作 |
| :--- | :--- | :--- |
| **移动 / 冲刺 / 战术滑铲** | `W A S D` / `Shift` / `Shift + C` | 左侧虚拟摇杆 |
| **转向 / 射击 / 全息红点开镜** | 鼠标移动 / `左键` / 按住 `右键` 或按 `V` 切换 | 右侧划屏 / `开火` `开镜` |

## 快速运行与工程结构

### 直接运行（免构建）
仓库根目录已内置打包好的三个独立入口文件，克隆后可直接启动静态服务或双击打开：
```bash
npx http-server . -p 8080 -c-1
```
- `index.html`：双游戏动态画布切换大厅（按 `1` 启动《星月夜骑士》，按 `2` 启动《断潮行动》）
- `starry-nightrider.html`：《星月夜骑士》独立单文件版（内置一键切换至《断潮行动》按钮）
- `saltline.html`：《断潮行动》独立单文件版（内置一键切换至《星月夜骑士》按钮）

### 源码结构与重新打包
```text
├── index.html                 # 双作典藏切换门户
├── starry-nightrider.html     # 《星月夜骑士》单文件零依赖成品（约 87 KB）
├── saltline.html              # 《断潮行动》单文件零依赖成品（约 671 KB）
├── scripts/
│   └── build.mjs              # esbuild 双游戏一键内联构建脚本
├── src-hub/
│   └── index.html             # 双作切换大厅源码
├── src-nightrider/            # 《星月夜骑士》模块化源码（原生 WebGL2 300 ES）
│   ├── math.js                # 圣雷米山谷地形场、星光河道、石拱桥与矩阵数学
│   ├── shaders.js             # 漩涡星穹、厚涂浮雕、实例化麦浪与各向异性 Kuwahara 滤镜
│   ├── world.js               # 尖顶教堂、风车、火焰柏树、星象画架与奔马/文森特建模
│   ├── audio.js               # 木吉他、大提琴、竖琴刮奏与四拍马蹄声学合成器
│   ├── main.js                # 骑乘物理、追尾相机、墨涡净除与关卡导演
│   ├── styles.css             # 普罗旺斯博物馆展签风 Vanilla CSS
│   └── template.html          # 页面与夜曲原声琴房模板
└── src/                       # 《断潮行动》模块化源码（Three.js + PBR + Web Audio）
```

修改源码后执行构建：
```bash
npm install
npm run build
```
