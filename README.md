## 快速运行与重新构建

仓库根目录已内置打包好的 **13 个零依赖独立静态文件**（`index.html` 大厅 + 4 款 3D 交互黑科技 + 8 款单文件游戏），克隆后直接启动任意静态服务即可畅玩：

```bash
npx http-server . -p 8080 -c-1
```

修改源码后一键重新内联打包全部十二款作品：

```bash
npm install
npm run build
```
