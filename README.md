# 断潮行动 SALTLINE: BLACK TIDE

**约 686 KB 单文件 HTML · 零外部贴图 / 零外部模型 / 零外部音频 · 浏览器直玩的雨夜港区 3D 战术射击游戏**

致敬近期 GitHub 爆火的 **Claude Fable 5.2《Saltline》** 纯代码「浏览器 3A 视觉范式」复刻与拓展之作。无需安装客户端，无需联网下载任何模型、图片或音频素材——所有湿混凝土积水反射贴图、集装箱瓦楞锈迹 PBR 材质、岸桥起重机与 200 米集装箱货轮模型、MK-18 全息红点突击步枪、机械敌群 AI 以及室内外混响枪声，均在浏览器内通过数学噪声、几何算法与 Web Audio API 实时物理生成。

---

## 核心特性

- **雨夜港区照片级氛围渲染（WebGL2 + ACES + HDR PMREM）**
  - 半浮点（`HalfFloatType`）程序化风暴夜空与钠灯高动态环境反射（`PMREMGenerator`），搭配 `UnrealBloomPass` 泛光后处理，令湿地积水、金属枪管与中继信标呈现真实高光倒影。
  - 动态雨幕与远海闪电惊雷系统——**支持室内外空间感知**：进入中央维修机库后头顶雨水自动遮蔽，步枪开火自动切换为浑厚的室内机库卷积混响（`ConvolverNode`）。
- **硬表面程序化 3D 建模**
  - **场景**：两座 44 米岸桥集装箱起重机（含随风暴摇摆的吊装集装箱与钠灯投射光）、205 米停靠货轮 *MV NORTHERN AEGIS*（旋转航海雷达与舰桥灯火）、可攀爬钢制斜坡与双层集装箱堆场、中央维修机库与东栈桥 *BREACHER-04* 隐身撤离快艇。
  - **第一人称武器台**：带战术护手手套的 **MK-18 断潮卡宾枪**，配备光学对准全息红点瞄具（右键开镜平滑居中对齐）、导轨战术手电（`F` 键）、消音器热辐射红热特效、可视黄铜弹窗弹匣、三段式换弹动画与抛壳物理弹跳。
  - **三类机械敌军与弱点判定**：
    1. **猎鸥无人机（GULL）**：双涵道旋翼空中机动，射击前发射红色激光锁定预警，中央光学镜头为 `2.25x` 暴击弱点。
    2. **猎犬四足机甲（HOUND）**：四足双关节步态逆运动学奔袭包抄，头部赤红目镜为 `2.25x` 暴击弱点。
    3. **港务官重装机甲（HARBORMASTER 首领）**：三处中继切断后镇守东栈桥，搭载加特林机炮与能量护盾——按 `Q` 投掷 **EMP 电磁脉冲手雷**可直接击碎其护盾并瘫痪敌群！
- **100% 纯代码 Web Audio 声学合成器（内置实时示波器音效台）**
  - 零 MP3/WAV 采样文件，主总线搭载砖墙动态压缩限幅器防止削波。
  - 实时合成：室外/室内双声学步枪射击、三段机械换弹、黄铜弹壳落地弹跳、三种材质脚步（积水飞溅 / 镀锌钢栈桥 / 湿水泥）、子弹擦耳呼啸、跳弹、EMP 电磁爆破、切断中继警报、远海惊雷，以及随战斗威胁度动态演进的暗黑合成器战术配乐。
  - 主菜单与暂停界面内置 **「声学合成台」**，可单独试听每一种程序化音效并实时观察波形。

## 快速运行与二次开发

### 方式一：直接打开单文件版（免构建）
仓库根目录下的 [`index.html`](./index.html) 已将引擎、着色器、材质、模型与声学合成器完整内联打包，无任何外部网络依赖：
```bash
npx http-server . -p 8080 -c-1
# 或直接用现代浏览器打开 index.html
```

### 方式二：修改模块化源码并重新打包
工程同时保留了清晰拆分的 ES Module 源码结构，便于阅读与二次扩展：

```text
├── index.html             # 单文件零外部依赖成品（约 686 KB）
├── scripts/
│   └── build.mjs          # esbuild 单文件内联打包脚本
└── src/
    ├── main.js            # 渲染管线、FPS 物理控制、任务导演与 HUD 投影
    ├── styles.css         # 军事战术风 Vanilla CSS 界面系统
    ├── template.html      # 语义化页面与声学合成台模板
    ├── math/
    │   └── noise.js       # 确定性伪随机、可平铺 Perlin/FBM/Worley 噪声与法线合成
    ├── materials/
    │   └── pbr.js         # 半浮点 HDR 环境图、湿混凝土积水与做旧集装箱 PBR 工厂
    ├── models/
    │   ├── world.js       # 岸桥起重机、205m 货轮、机库、中继塔、撤离快艇与碰撞体
    │   ├── weapon.js      # 第一人称 MK-18 全息红点步枪、战术手臂与换弹/后坐力动画
    │   └── enemies.js     # 猎鸥无人机、猎犬四足机甲、港务官首领 AI 与室内外雨幕系统
    └── audio/
        └── synth.js       # 纯 Web Audio API 物理音效合成器与动态战斗配乐
```

安装依赖并构建单文件 `index.html`：
```bash
npm install
npm run build
```
